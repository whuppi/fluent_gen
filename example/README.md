# fluent_gen example

The generator's consumer fixture AND its showcase. A minimal `.ftl`
set under `lib/i18n/` runs through the real build_runner integration
to produce `lib/i18n/app_messages.g.dart`, and `lib/main.dart` tours
every generated surface: the `AppLocale` enum (values, base,
`tryParse`, `negotiate`, the accessor manifest), every inference shape
(comment pins, plural and string selectors, `NUMBER` / `DATETIME`
arguments, transitive message references, the `$when` reserved-word
escape), per-attribute methods, `AsSpans` markup siblings, error
out-lists, and a partial locale reporting a missing message loud.

## Run

```bash
cd example

# regenerate lib/i18n/app_messages.g.dart from the .ftl sources
fvm dart run build_runner build --delete-conflicting-outputs

# the tour
fvm dart run lib/main.dart
```

## Tests

```bash
# from the package root — regenerates through the real build_runner,
# proves the output analyzes clean, then runs this suite:
make test-example

# or directly
cd example && fvm dart test
```

Five suites, each pinning a different generator guarantee:

| Suite | What it proves |
|---|---|
| `generated_smoke_test` | Every accessor formats correctly through a real CLDR backend — types, plurals, attributes, spans, errors |
| `generated_analyzes_clean_test` | The emitted file passes `dart analyze` under `package:lints/recommended` with no blanket suppression |
| `locale_enum_test` | `AppLocale` values, `tryParse`, the negotiation ladder (exact → truncated subtags → language prefix → fallback), `load()` from embedded FTL |
| `no_unused_messages_test` | The `unusedFluentAccessors` helper from `package:fluent_gen/testing.dart` finds no orphaned messages in this fixture |
| `showcase_test` | Runs `lib/main.dart`'s tour and pins every output line — including the FSI/PDI bidi-isolation marks, asserted as `\u2068` / `\u2069` escapes |

## What's inside

| Piece | Purpose |
|---|---|
| `lib/i18n/en.ftl` | The base locale — every shape the generator supports appears at least once (see its header comment) |
| `lib/i18n/fr.ftl` | A deliberately partial locale — missing-message and orphan-message warnings are part of the fixture |
| `build.yaml` | The builder config: `base_locale`, `ftl_dir`, `class_name`, `output_path`, and `bundle_ftl: true` so `AppLocale.load()` works with no asset pipeline |
| `lib/i18n/app_messages.g.dart` | The committed generated output — regenerated by `make test-example`, so a stale commit surfaces as a working-tree diff |
| `lib/main.dart` | The showcase — every generated surface, output pinned |

## One file on purpose

The whole tour lives in `lib/main.dart` because pub.dev renders that
file as the package's Example tab — splitting it would hide everything
else from that page.

## Generated code is committed on purpose

`app_messages.g.dart` is checked in so the fixture is readable without
running a build, and so an emitter change shows up as a reviewable
diff. It is never edited by hand — `make test-example` regenerates it
through the real build_runner on every gate run, so a hand edit or a
stale commit surfaces as a working-tree diff the moment the gate runs.
